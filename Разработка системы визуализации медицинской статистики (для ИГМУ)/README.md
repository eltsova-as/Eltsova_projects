# Туберкулёз: мониторинг эпидситуации и ресурсов (Иркутская область / РФ)

## 🔗 Ссылка на дашборд

> *[https://datalens.yandex/htf2vrroq1rm1?_embedded=1&_theme=dark]*

**Цель проекта:** Создание системы поддержки принятия обоснованных управленческих решений для повышения эффективности противотуберкулезной помощи населению Иркутской области.

**Основные задачи:**
- Консолидировать и привести к единому формату данные из источников
- Рассчитать интенсивные показатели (заболеваемость, смертность, распространённость на 100 тыс. населения)
- Разработать интерактивный дашборд с фильтрами по году, региону, форме туберкулёза и возрастной группе
- Подготовить аналитический отчёт с выводами и рекомендациями

**Моя роль и вклад (командный проект)**

**Этап 1. Обработка данных (командная работа)**  
В составе команды участвовала в подготовке данных: приведение таблиц из широкого формата в длинный, сведение данных по годам в единую таблицу, очистка, стандартизация, унификация названий показателей.

**Этап 2. Моя индивидуальная работа:**

- **Расчёт производных метрик**:  
  вычисление заболеваемости, смертности, распространённости на 100 тыс. населения, расчёт структуры по формам, полу и возрасту, расчёт коэффициента хронизации.

- **Разработка дашборда**:  
  создание интерактивного дашборда в Yandex DataLens (9 вкладок, картограммы, линейные и столбчатые диаграммы, фильтры и селекторы).

- **Аналитика и презентация**:  
  подготовка итогового отчёта с ключевыми выводами по эпидситуации, формулировка рекомендаций для управления, презентация дашборда заказчику.

**Результат:** Дашборд признан одним из лучших в проекте.

**Стек:** Yandex DataLens, Python (pandas), Excel/CSV

**Topics:** Yandex DataLens, BI, дашборды, визуализация данных, Python, pandas, обработка данных, медицинская аналитика, эпидемиология, продуктовый анализ

## 📈 Ключевые выводы

| Показатель | Тренд |
|------------|-------|
| Заболеваемость в РФ | Снижение в 3,4 раза (2000 → 2024) |
| Распространённость в РФ | Снижение в 5,7 раза (2002 → 2024) |
| Смертность в РФ | Снижение в 6,4 раза (2005 → 2023) |
| Заболеваемость в ИО | Снижение на 56% (2016 → 2024) |
| Гендерный разрыв | Мужчины болеют в 2,5 раза чаще женщин |
| Первичная МЛУ | Рост с 16% до 27% (2016 → 2024) — тревожный сигнал |
| Кадровый дефицит | Укомплектованность физическими лицами — только 60% |

## 💡 Рекомендации для управления

1. **Усилить меры по снижению первичной МЛУ** — рост с 16% до 27% требует внимания
2. **Сосредоточить профилактику на мужском населении** — заболеваемость в 2,5 раза выше, чем у женщин
3. **Укрепить кадровый потенциал** — укомплектованность физическими лицами составляет только 60%
4. **Продолжить программы ранней диагностики** (особенно ФЛГ-скрининг)
